    Anagram strategy

    What makes an exact anagram different?

    An exact anagram is stricter than a general word unscramble. If you enter SILENT, a valid result must contain the same six letters with the same frequencies. LISTEN qualifies; a shorter word such as LINE does not because it leaves letters unused.

    This distinction matters in anagram puzzles, name puzzles and clues where every character is intended to be accounted for. When you only need words that can be built from some of your letters, use the Word Unscrambler instead.

    1

    Keep duplicate letters

    Repeated letters matter. LETTER contains two Ts and two Es, so an exact result must preserve both counts.

    2

    Filter after the letters

    If a clue suggests a beginning, ending or internal sequence, add it after entering the full rack. The result still has to use every supplied tile.

    3

    Use wildcards carefully

    A ? can stand for one missing letter. With a wildcard, tile-score sorting becomes more useful because different replacements can change the score.

    Example: SILENT

    SILENT and LISTEN contain exactly one S, I, L, E, N and T. That makes LISTEN an exact anagram. By default the solver excludes the original input itself; turn on “Include the original word” when you want to see it too.

    When no result appears

    A blank result does not prove that no phrase or proper-name anagram exists. LetterToolkit searches its included English word list, not every name, phrase, abbreviation or specialist term. Double-check spelling, repeated letters and any optional filters first.

    Does letter order matter?

    No. Only the letters and their frequencies must match.

    Can I use a wildcard?

    Yes. Add ? for one unknown letter. The result still uses the full rack length.

    Can I solve multi-word phrases?

    This tool currently returns single dictionary words. Phrase anagrams require a much larger search space and are not represented as complete results here.
