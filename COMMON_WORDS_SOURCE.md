# Common five-letter word ranking source

`common-5-letter-words.txt` is a compact frequency-oriented shortlist derived from the English frequency data in Hermit Dave's **FrequencyWords** project and then intersected at runtime with LetterToolkit's existing five-letter dictionary.

Source repository: `hermitdave/FrequencyWords`
Source file used for ranking: `content/2018/en/en_50k.txt`
License: MIT License, Copyright (c) 2016 Hermit Dave.

The shortlist is used only to prioritize familiar English words in the five-letter finder. It is not presented as an official Scrabble, Wordle, or other game dictionary. The full LetterToolkit dictionary remains available as a separate search mode.
