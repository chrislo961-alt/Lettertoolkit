LetterToolkit 6.1 - AdSense Quality Edition

Purpose: address the AdSense "low value content" feedback by improving editorial value and reducing thin-page indexation.

Changes:
- Added 9 original, substantial editorial guides plus a Guides hub.
- Expanded About page with purpose, methodology, dictionary caveats, privacy and editorial approach.
- Added Guides discovery section to homepage.
- Reduced sitemap from hundreds of generated URLs to a curated set of strong pages.
- Marked most mass-generated word-list pages noindex,follow while retaining them for users.
- Kept a smaller set of useful word-list landing pages indexable.
- Removed empty Advertisement placeholders while site is not approved.
- Kept the AdSense verification script so ownership remains verifiable.
- Writer and all core interactive tools remain included.

Recommended before requesting AdSense review:
1. Deploy the entire folder.
2. Confirm /guides/, /about/, /contact/, /privacy/, /terms/, /writer/ and core tools load.
3. Submit the updated sitemap in Search Console.
4. Give Google time to crawl the updated site before requesting review.
