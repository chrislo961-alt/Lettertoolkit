Write with fewer interruptions

An offline writing app you can install from the browser

LetterToolkit Writer is a progressive web app. After the required files have loaded successfully, supported browsers can install it for quicker access and cache the editor for offline use.

Open Writer – free
01

Install on desktop or Android

Chrome and Edge can display an Install Writer button when installation requirements are met. The installed app opens in its own window and keeps the same local document library.

02

Add to an iPhone or iPad

Open Writer in Safari, use the Share menu and choose Add to Home Screen. Apple devices may handle storage and offline behavior differently, so keep downloaded backups of important work.

03

Offline is local

Offline mode does not create cloud synchronization. Documents remain tied to that browser profile and device unless you export and move the file yourself.

Before you begin

No account is required. Documents are stored in this browser, so clearing site data can remove them. Download important work as a backup. DOCX support covers common content and may simplify advanced layouts.

How to use LetterToolkit Writer

  1. Open Writer and choose a blank document or template.
  2. Write directly or open a DOCX, TXT, HTML or Markdown file.
  3. Format and review the document while local autosave protects the draft.
  4. Download DOCX, TXT, HTML or Markdown, or print to PDF.
