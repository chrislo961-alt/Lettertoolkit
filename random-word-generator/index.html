    Are the words truly random?

    Random mode shuffles the matching dictionary pool in your browser and takes a fresh unique sample each time.

    Can I generate only five-letter words?

    Yes. Set both minimum and maximum length to 5.

    Do repeated required letters matter?

    Yes. Required letters preserve counts, so entering EE only returns words containing at least two Es.

    Are my filters stored?

    The tool does not save them to an account. If you use Copy search link, the selected settings are encoded in that URL so you can bookmark or share them.
