# LetterToolkit 3.4

Static SEO-focused word-tool platform for Cloudflare Pages.

## New in 3.4
- Random Word Generator at `/random-word-generator/`
- Generate 1–50 words
- Optional length, starts-with, and contains filters
- Updated homepage, navigation, and sitemap

Upload all files to the root of the GitHub repository. No build command is required.

## Version 3.4

Added a spelling-based Rhyme Finder at `/rhyme-finder/`, updated navigation, homepage cards, statistics, and sitemap.
