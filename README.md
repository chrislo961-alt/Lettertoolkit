# LetterToolkit 3.2

Static Cloudflare Pages website with six browser-based word tools.

## Included tools
- Word Unscrambler
- Anagram Solver
- Word Finder
- Wordle Helper
- Crossword Solver
- Scrabble Helper

The Scrabble Helper supports wildcard tiles, minimum length, letter-position filters, and sorting by standard English Scrabble tile score.

Upload all files and folders to the root of the GitHub repository. No build command is required.
