    How the filters work together

    Think of every field as another rule

    Length defines the overall shape, pattern fixes known positions, Contains searches for an exact sequence, and Required letters checks that individual letters appear somewhere in the word.

    1

    Use pattern for positions

    A pattern such as A??LE means five letters, beginning with A and ending with LE, while the two middle positions may vary.

    2

    Know Contains vs Required

    Contains ING requires the sequence I-N-G together. Required letters ING only requires I, N and G somewhere in the word, in any order. Repeated required letters are counted separately.

    3

    Share useful searches

    Use Copy search link to save the current filters in the URL. Opening that link restores the fields and reruns the search automatically.

    Worked examples

    From vague clue to useful shortlist

    Example 1: A??LE. Enter length 5 and pattern A??LE when you know exact positions.

    Example 2: starts with ST, requires R, excludes AEI. Use Required letters for R if it may appear anywhere. This is different from Contains R only when you enter multiple letters as a sequence.

    Example 3: requires EE. Enter EE when the answer must contain at least two Es; the finder now preserves repeated-letter counts.

    Example 4: contains ING. If the letters must appear consecutively, use Contains sequence rather than Required letters.

    Accuracy and word lists

    A spelling match is not always the final answer

    The finder searches LetterToolkit's English word dataset. Different dictionaries and games make different decisions about regional spellings, inflections, archaic words and specialist terms. Use uncommon matches as candidates to verify.
