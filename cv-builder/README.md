# LetterToolkit 6.3 – CV Builder Polish

This update only replaces the CV Builder frontend.

## Improvements
- Matches LetterToolkit branding/navigation
- Clear 5-step flow
- Cleaner mobile layout
- AI suggestions go into a review area first
- Apply buttons let the user approve each section
- Cleaner privacy messaging
- Removes prototype/backend setup copy
- 3 design choices
- Existing Cloudflare Worker URL already connected
- PDF via print, TXT, JSON backup, cover letter

## Install
Copy the `cv-builder` folder into the root of your LetterToolkit repository and replace the existing folder.

Do not delete the Cloudflare Worker. No Worker redeploy is required for this frontend-only update.
