Quality & transparency

Editorial and tool quality policy

LetterToolkit is built around working browser tools first. This page explains how calculations, guides, word data and corrections are handled so readers can judge the results instead of taking them on trust.

Our primary purpose

LetterToolkit helps people count, analyze, clean and format text in the browser. Word-finding and puzzle tools are a secondary part of the site. We do not create pages simply because a keyword exists; a page should either perform a useful task or explain a real method that helps someone complete that task.

How the text tools are tested

Core text tools are checked with ordinary text, empty input, repeated whitespace, punctuation, line breaks and Unicode characters. When a tool uses an estimate rather than an exact rule, the assumption is shown on the page. For example, reading-time and speaking-time tools use stated words-per-minute assumptions rather than presenting an estimate as a measured fact.

Counting rules can differ between editors. LetterToolkit therefore explains its own rules and recommends checking the final destination when a school, publisher or form enforces a strict limit.

How word and puzzle results are produced

Word tools use a shared English word dataset and deterministic filters such as word length, starts with, ends with, contains, fixed positions, required letters and excluded letters. A match in our dataset is not presented as an official ruling for a branded game or tournament. Different dictionaries can disagree about regional, historical, technical and inflected words.

Large automatically generated word-detail and pattern pages are not treated as editorial articles. We keep them out of the primary indexed content surface unless a page has been deliberately reviewed and provides a useful standalone experience.

Guides and authorship

Guides are written and maintained by LetterToolkit for the purpose of explaining how to use the tools and how the underlying task works. We prefer concrete examples, limitations and repeatable methods over generic filler. When automation assists with drafting or maintenance, the published page is still reviewed for factual consistency with the tool before it is treated as editorial content.

Corrections and updates

We update pages when a tool changes, a stated rule becomes inaccurate or a useful correction is reported. If you find a broken calculation, questionable word, misleading explanation or accessibility issue, send the page address, the input you used and the result you expected through the Contact page.

Advertising and independence

Advertising may help fund hosting and continued development, but it should not replace or obscure the main purpose of a page. Tool functionality, explanations and word results are not changed in exchange for advertising placement. Pages that are intentionally excluded from search because they are thin or automatically generated are also excluded from the site's primary monetization surface.

What we do not claim

LetterToolkit is not an official dictionary, academic submission system or branded game authority. It is a practical browser toolkit. Where an external rule matters, such as a formal word-count limit or game dictionary, the relevant official source should be the final authority.
