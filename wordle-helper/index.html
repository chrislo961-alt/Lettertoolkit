    Word-game strategy

    Translate feedback into useful constraints

    A green letter fixes both the letter and its position. A yellow letter tells you that the letter belongs in the word but not in the position where you tried it. A gray letter usually removes that letter from consideration. Combining those facts is more useful than simply generating a long list of five-letter words.

    For example, a green pattern of ?A??E means positions two and five are fixed. If R and T are known to be present, add them as yellow letters. Exclusions then remove candidates containing letters you have already ruled out.

    1

    Use information, not guesses

    When many candidates remain, a guess containing several untested common letters can reveal more than guessing two nearly identical candidates.

    2

    Watch repeated letters

    Gray feedback is more subtle when the same letter appears twice in a guess. One copy can be valid while another is marked gray because the answer contains that letter only once.

    3

    Recheck contradictions

    If no candidates remain, inspect your yellow and gray entries. A letter accidentally placed in both groups can make the filters impossible to satisfy.

    Candidate lists are not answer lists

    The included dictionary is broader than the answer set used by any particular daily word game. Some valid dictionary words may never be chosen as puzzle answers, while a game's accepted-guess list may differ. Treat results as candidates to reason about rather than a claim about today's official solution.

    A stronger next-guess approach

    When you have several plausible candidates, compare which letters differ between them. A strategically chosen test word can cover those uncertain letters in one turn. When only one or two candidates remain, direct guesses become more sensible.

    Why can a gray letter still matter when letters repeat?

    Feedback is based on how many copies of a letter occur in the answer. If your guess uses a letter twice but the answer contains it once, one tile can receive positive feedback and the other can be gray.
