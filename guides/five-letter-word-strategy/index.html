How to Narrow a Five-Letter Word List

A constraint-first method for five-letter puzzles, from Wordle to pattern clues.

Length is only the first filter

Thousands of five-letter words exist in broad dictionaries. The useful step is combining length with position, inclusion and exclusion clues.

Fix known positions

If the third letter is A, encode that position before considering other clues. Positional information usually removes more candidates than a vague included-letter clue.

Add required letters

A required letter can occur in more than one position. If a puzzle says the letter exists but not where, avoid accidentally fixing it too early.

Exclude carefully

Remove letters only when the puzzle truly rules them out. Repeated-letter feedback can make a letter look absent even when one copy is present.

Rank candidates by usefulness

When several candidates remain, prefer a guess that tests distinctions between them. This is often better than choosing the first familiar word.

Dictionary caveat

Large word lists contain rare forms and regional variants. Puzzle answer lists are usually smaller, so context and official rules still matter.
