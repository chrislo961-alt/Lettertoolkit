Privacy & production notes

Does this upload my CV?

No. This prototype processes supported files in the browser and autosaves form fields to localStorage. No server is used.

Where does real AI fit?

Production AI should run through a server-side API route so credentials stay secret and CV data can be handled with clear retention/deletion rules.
